# ZPS Callout Suppress

Blocks NavBot survivor bots from posting "spotted at" enemy callouts in team chat. Real players and other bot messages are unaffected.

## Requirements

- SourceMod
- NavBot

## Install

1. Copy `zps_callout_suppress.smx` to `addons/sourcemod/plugins/`

## ConVars

Set in `cfg/sourcemod/zps_callout_suppress.cfg` (auto-generated on first load).

| ConVar | Default | Description |
|---|---|---|
| `zps_callout_suppress_enabled` | `1` | Turn the plugin on/off. |
